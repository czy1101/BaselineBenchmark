# MetaX independent baselines

This backend contains comparison-side baselines for GLA, NSA, KDA and
SageAttention.

- `ops/`: implementation snapshots or external-runtime adapters
- `tests/`: baseline-side correctness entrypoints
- `benchmarks/`: baseline-side benchmark entrypoints

No FlagAttention adapted operator source is included.
Generated binaries, wheels, caches and result files are excluded.
